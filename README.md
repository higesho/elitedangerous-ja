# エリート・デンジャラス 日本語化パッチ

Steam 版「Elite Dangerous」を日本語で遊べるようにする、非公式のファンメイド日本語化パッチです。
開発元・販売元とは関係ありません。

- サイト（紹介・入れ方）: https://higesho.github.io/elitedangerous-ja/
- ダウンロード: [リリース](https://github.com/higesho/elitedangerous-ja/releases/latest) の `EliteDangerous_JP.zip`
- 日本語化プロジェクトの一覧: https://higesho.github.io/ja/

## 入れ方

1. `EliteDangerous_JP.zip` の中の `dinput8.dll` を、`EliteDangerous64.exe` があるフォルダ（ゲームのフォルダの中の `Products\elite-dangerous-odyssey-64`）に置きます。
2. いつもどおり Steam から起動します。

外すときは、`dinput8.dll` を消せば英語版に戻ります。
ゲームのファイルは書き換えません。配布物には原作のプログラムやデータは入っていません。

GalNet の記事など、サーバーから届く文章と固有名詞は英語のままです。用語は [Elite:Dangerous 日本語 Wiki](https://wikiwiki.jp/elitejp/) に合わせています。

ジャーナル（`Journal.*.log`）は英語版と同じ内容で書かれ、ゲームがサーバーへ送るジャーナルも変わりません（v1.1 から）。
